# FocusGrid  | Personal Productivity Dashboard

A modern, interactive, and all-in-one web-based productivity dashboard designed to help you organize your daily tasks, stay focused, and plan your day effectively. Built using clean, vanilla frontend web technologies.

---

## ✨ Features

- **⏱ Live Clock & Real-time Info:** Displays real-time date, time, and location data dynamically updated via live APIs.
- **🎨 Dynamic Theme Toggle:** Easily switch between light/dark or custom color themes to match your preference.
- **📋 Personalized To-Do List:** Create, manage, and prioritize your daily tasks with custom details and importance flags.
- **📅 Time-Slot Daily Planner:** Hourly schedule breakdown allowing you to organize your entire day systematically.
- **⏳ Integrated Pomodoro Timer:** A 25-minute focus work session timer complete with Start, Pause, and Reset controls.
- **🎯 Daily Goals Tracker:** Quick-entry daily goal section to keep your main targets visible and actionable.
- **💡 Daily Inspirational Quotes:** Automatically fetches daily motivational quotes to keep you driven throughout the day.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **APIs:** Real-time Clock/Geolocation & Dynamic Quote API
- **Styling:** CSS Grid, Flexbox, Dynamic Themes & Variables
